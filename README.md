# 像素日志 · PIXEL LOG

一个零依赖的像素风中文博客示例。使用原生 HTML、CSS 和 JavaScript，无需构建，也不请求外部字体、图片或脚本。

## 预览

直接用浏览器打开 `index.html` 即可。

也可以在当前目录启动一个本地服务器：

```bash
python3 -m http.server 8080
```

然后访问 <http://localhost:8080>。

## 已实现

- 8 篇完整示例文章，包含文章列表、封面、阅读时间和详情页
- 基于 URL Hash 的文章路由，支持前进、后退和直接分享文章链接
- 6 个标签分类、标签计数、关键词搜索和空结果状态
- 深色 / 浅色主题，记忆用户选择；未手动选择时跟随系统
- CSS 像素营地：星光、流云、篝火、人物与视差场景
- 首页循环打字机、文章引言打字机
- 鼠标像素粒子与点击迸发效果（触屏设备不启用）
- 滚动视差、卡片入场、阅读进度、文章目录和故障艺术
- 响应式布局，覆盖桌面、平板、手机和 280px 超窄预览面板
- 键盘焦点、跳转主内容、语义化标签及移动端菜单

## 减少动态效果

- 自动响应系统 `prefers-reduced-motion` 设置。
- 系统要求减少动态效果时，关闭粒子、视差、打字机、故障艺术和循环动画。
- 桌面端顶栏的 `✦` 按钮也可以手动开关动效，选择会保存在本地。
- 系统偏好的优先级高于手动开关，无法在系统要求减少动态效果时强行开启动画。

## 文件结构

```text
index.html   页面结构与首页各个区块
styles.css  主题、像素插画、响应式布局与动画
app.js      文章数据、筛选、路由、主题及动效控制
README.md   使用说明
```

## 修改内容

文章数据集中在 `app.js` 顶部的 `articles` 数组中。每篇文章包含：

- `slug`：详情页地址，例如 `#/post/build-a-cozy-pixel-world`
- `title`、`excerpt`、`date`、`readTime`
- `tag`：卡片主标签；`tags`：筛选时归属的全部标签
- `sections`：详情页章节及正文
- `art`、`coverBg`、`coverAccent`：像素封面样式

标签名称与颜色集中在 `TAGS` 对象中。主题变量位于 `styles.css` 的 `:root` 和 `html[data-theme="light"]`。

## 说明

这是前端演示项目，文章与订阅数据均不连接后端。订阅表单不会保存或发送邮箱，提交时也会明确提示。
